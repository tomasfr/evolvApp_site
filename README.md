# EvolvApp — landing page

Landing page estática responsiva feita com HTML, CSS e JavaScript puro. A identidade visual usa as cores do app (`#101318`, grafite e `#FFC914`), a logo existente e Montserrat.

As capturas reais em `assets/` substituem os painéis ilustrativos. A página aponta para cópias em `assets/public/` nas quais o nome e o e-mail visíveis no cabeçalho das telas foram cobertos; os arquivos enviados foram mantidos intactos. O favicon e o ícone Apple usam o símbolo amarelo da marca em `evolvApp/assets/images/logo_amarela.png`.

A política de privacidade está em `privacidade.html`. Antes de publicá-la, complete a identificação legal do controlador e um canal direto para solicitações de privacidade, que ainda não constam no projeto.

## Como abrir

Abra `index.html` no navegador ou sirva esta pasta com qualquer servidor estático. Não há etapa de build nem dependências de projeto.

Os links principais da landing page navegam entre as seções até que exista uma URL pública do app para receber os CTAs.
